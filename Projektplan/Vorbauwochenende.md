## 4. To-Dos

### Vor dem Wochenende
- [ ] Materialliste finalisieren
- [ ] Werkzeug auf Vollständigkeit prüfen
- [ ] Werkstatt / Halle reservieren
- [ ] Verpflegung organisieren
- [ ] Teilnehmer:innen bestätigen

### Während des Wochenendes
- [ ] Bühnenrahmen vormontieren
- [ ] Podestplatten zuschneiden
- [ ] Stützen / Streben vorbereiten
- [ ] Kabelbäume vorkonfektionieren
- [ ] Schrauben/Beschläge sortieren und beschriften
- [ ] Transportkisten packen und beschriften

### Nach dem Wochenende
- [ ] Werkstatt aufräumen
- [ ] Restmaterial dokumentieren
- [ ] Übergabe-Foto / Doku an Aufbauteam
- [ ] Lessons Learned notieren
